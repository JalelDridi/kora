**Goal:** A visitor drafts a 4-3-3 of Tunisian footballers from Ligue 1 club histories, one spin per slot, simulates a 30-match season, shares the record, and sees today's top sides on a board, in three locales on a 320 px phone.

**Architecture:**
- A pure engine `src/engine/season/` (no I/O, relative `.ts` imports, runs under `node file.ts`): candidate data and ratings derived from `data/pool.json` (`data.ts`, `rating.ts`), seeded randomness (`prng.ts`), spins with fallbacks (`spin.ts`), draft rules (`draft.ts`), the season (`simulate.ts`) and the share text (`share.ts`). Property-tested.
- Ratings are **derived, not stored** (T-S3-1): `buildSeasonData(pool, files, year)` runs once per server instance (`src/season/data.server.ts`, like `src/chkoun/attributes.server.ts`) and once per `pnpm data:check`, which refuses a pool that could leave a slot empty. Why not `pool.json`: it holds facts with provenance (P26); a rating is the formula's opinion, and a formula change must not need a data rebuild or a nightly pull request.
- The server runs everything (D-S3-14). `POST /api/season/draft` signs the draft in a token (T-S3-4) and returns spins and candidates; `POST /api/season/play` replays the draft, simulates, and records the visitor's first season of the day in Redis (hash + sorted set); `GET /api/season/board` (CDN `s-maxage=30`) re-simulates and returns today's top sides; `GET /api/season/replay` replays a shared squad. The nightly cron copies seasons to Postgres. Redis off: playable, "saved on this device".
- The page `/[locale]/season` is a static shell with one client island; the share page `/[locale]/season/r/[day]/[xi]` renders a replay on the server.

**Tech Stack:** Next.js 16.3.8 (App Router, route handlers), next-intl 4.14.9, Prisma 7.10 + `pg`, `@upstash/redis` 1.39.0, Vitest 5 + `fast-check` 3.23.2 (already a dev dependency), Playwright 1.63 + `@axe-core/playwright`, Lighthouse CI 0.15.1, PostHog (cookieless). Stretch: `next/og`.

```ts
import type { RatingInputs } from "./types.ts";

// D-S3-5: one documented formula (data/README.md, "30–0 ratings"). Each part
// is scaled to 0..1, weighted by line, then mapped onto 60..99.
export const RATING = {
  floor: 60, span: 39, curve: 0.8,
  bandCaps: [0, 5, 20, 45, 75],                     // D-S3-6
  capsFull: 100, appsFull: 200, titlesFull: 6,
  eraCaps: { 1990: 1.15, 2000: 1, 2010: 1, 2020: 1.1 }, // fewer matches in the 1990s; careers still open
  gpcFull: { goalkeeper: 0, defender: 0.1, midfielder: 0.25, forward: 0.5 },
  titleWeight: { league: 1, cup: 0.5, caf: 1.5 },
  afconBonus: 0.05,
  weights: {
    goalkeeper: { caps: 0.5, goals: 0, apps: 0.3, titles: 0.2 },
    defender: { caps: 0.45, goals: 0.05, apps: 0.3, titles: 0.2 },
    midfielder: { caps: 0.4, goals: 0.15, apps: 0.25, titles: 0.2 },
    forward: { caps: 0.35, goals: 0.3, apps: 0.2, titles: 0.15 },
  },
} as const;

const log01 = (x: number, full: number) => Math.min(1, Math.log1p(Math.max(0, x)) / Math.log1p(full));

export function rate(i: RatingInputs): number {
  const w = RATING.weights[i.line];
  const full = RATING.gpcFull[i.line];
  const t = i.titles;
  const raw =
    w.caps * log01(i.caps * RATING.eraCaps[i.decade], RATING.capsFull) +
    w.goals * (full === 0 ? 0 : Math.min(1, i.goalsPerCap / full)) +
    w.apps * (i.apps === null ? 0 : log01(i.apps, RATING.appsFull)) +
    w.titles * Math.min(1, (t.league * RATING.titleWeight.league + t.cup * RATING.titleWeight.cup + t.caf * RATING.titleWeight.caf) / RATING.titlesFull) +
    (i.afcon2004 ? RATING.afconBonus : 0);
  return Math.round(RATING.floor + RATING.span * Math.min(1, raw) ** RATING.curve);
}
```
`data.ts` core: for each player, keep spells with `!loan && clubId in ligue1 && from !== null`; for each decade where `from <= decade + 9 && (to ?? currentYear) >= decade`, group spells by `(clubId, decade)`; `apps` = sum of non-null apps or null; titles = distinct honours of that club with `spell.from <= seasonEnd <= (spell.to ?? currentYear)` for any grouped spell (`tn_ligue1` → league, `tn_cup` → cup, `caf_cl`/`caf_cc` → caf); `capsSure = ["high","medium"].includes(prov.caps?.confidence) || prov.caps?.bandAgreed === true`; caps = `capsSure ? caps : RATING.bandCaps[capsBand(caps)]`; `goalsPerCap = caps >= 5 ? goals / caps : 0` (on the stored count); `goalsDoubt` and `historyDoubt` when that field's confidence is `low` or missing; `afcon2004 = files.afcon.footballers.includes(wikidataId)`. Sort each index list by footballer id; `combos` per footballer sorted; `slotCode = \`${id}.${combos.get(id).indexOf(tripleKey(...))}\``.

```ts
export function spin({ data, line, taken, rand }: SpinInput): Spin {
  const open = (clubId: string, decade: Decade) =>
    (data.index.get(tripleKey(clubId, decade, line)) ?? []).filter((c) => !taken.has(c.footballerId));
  const pickOf = <T>(xs: readonly T[]) => xs[Math.floor(rand() * xs.length)];
  const clubId = pickOf(data.clubIds);   // D-S3-1: every club as often
  const decade = pickOf(DECADES);
  const pairs = (clubs: readonly string[], decades: readonly Decade[]) =>
    clubs.flatMap((c) => decades.map((d) => [c, d] as const)).filter(([c, d]) => open(c, d).length > 0);
  const ladder = [
    [1, pairs([clubId], [decade])], [2, pairs([clubId], DECADES)],
    [3, pairs(data.clubIds, [decade])], [4, pairs(data.clubIds, DECADES)],
  ] as const;
  for (const [level, found] of ladder) {
    if (found.length === 0) continue;
    const [c, d] = pickOf(found);
    return { line, clubId: c, decade: d, level, candidates: shuffle(open(c, d), rand).slice(0, 5) };
  }
  throw new Error(`no ${line} left`);
}
```

```ts
export const SIM = { base: 1.3, k: 0.055, home: 0.15, maxGoals: 9 };

export function simulateSeason({ day, xi, table }: SimInput): Season {
  const rand = hashRand(`season|${day}|${canonicalXi(xi)}`);
  const rating = teamRating(xi.map((s) => s.rating));
  const replaces = mostDrafted(xi);
  const opponents = shuffle(table.filter((o) => o.clubId !== replaces), rand);
  if (opponents.length !== 15) throw new Error("the table must hold the side's club and 15 others");
  const matches: Match[] = [];
  for (const leg of [0, 1])
    opponents.forEach((o, i) => {
      const home = (i % 2 === 0) !== (leg === 1);
      const edge = SIM.k * (rating - o.strength) + (home ? SIM.home : -SIM.home);
      const goalsFor = poisson(SIM.base * Math.exp(edge), rand(), SIM.maxGoals);
      const goalsAgainst = poisson(SIM.base * Math.exp(-edge), rand(), SIM.maxGoals);
      matches.push({ round: leg * 15 + i + 1, opponent: o.clubId, home, for: goalsFor, against: goalsAgainst });
    });
  return summarise(matches, rating, replaces);
}
```

## Risks and mitigations

| Risk | Mitigation |
| --- | --- |
| A slot comes up empty after a pool change | `data:check` refuses the pool in the nightly pull request; 2,000-draft test on the committed pool; the fourth fallback level |
| A forged squad reaches the board | Signed draft; the season endpoint replays every spin; the board re-simulates every entry; scores are the server's |
| Ratings feel wrong (legends' noisy goals, missing apps, few honours after 2022) | Inputs and "?" on every card; the formula in one constant and in `data/README.md`; Jalel's corrections go to overrides or the curated files |
| 30–0 too easy or impossible | Tuning tests pin the rates by team rating and for greedy drafts on the real pool |
| A replay changes after the pool changes (a rating moved) | Accepted: the replay page says the season is replayed with today's ratings; the board shows only today |
| A visitor tries squads through the replay endpoint before playing | Accepted: only drafted squads can be played; the first season of the day per visitor counts |
| Two ids for one visitor while the cookie path moves | Today's endpoint re-issues the id under `/api`; worst case one day's season record under a second id |
| Upstash command budget | No rate-limit count on picks; CDN cache on board and replay; stop rule at 50% |
