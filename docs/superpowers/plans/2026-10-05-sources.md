> **Approved by Jalel on 5 October 2026** ("I reviewed your plans, go"). Written on 4 October 2026. Nothing in it was run. Numbers marked [M] come from `data-sources-2b-wikipedia-squads.md` and `data-sources-2a-apis-and-sites.md`; [U] means not verified.

> **Decided by Jalel on 4 October 2026 (question tool):** S7 = (a) a squad list never chooses the club, it votes and a difference is flagged for him. S8 = (a) the national squad table may set the caps when it is the newest dated source. **S21 = (b)** a private-check "differs" is a flag AND the field is rated low (this is stricter than P43's first wording; Task A1 updates P43's text). S23 = the two sites are named, and P43 stays as written. Every other choice (S1 to S6, S9 to S20, S22, S24 to S30): as recommended. Where the tasks below say "Under S21b", that is now the rule.

> **For agentic workers:** use superpowers:subagent-driven-development or superpowers:executing-plans, task by task. Steps use `- [ ]`.

**Goal:** Part A adds the Wikipedia squad lists as a dated, published witness for `clubId` and `caps` in the nightly build. Part B adds a private witness: Transfermarkt and national-football-teams.com, read by hand on Jalel's PC each week. The repo stores only verdicts ("checked on, agrees / differs / not found"), never the sites' values.

**Architecture:**
- Part A is a new pure parser (`wiki/squads.ts`), a pure matcher (`squads/match.ts`), pure witness rules (`squads/evidence.ts`) used by `mergePlayer`, and one optional source in `run.ts`.
- Part B is a separate entry point, `src/pipeline/witness-cli.ts`. Its pure modules live under `src/pipeline/witness/`, and it writes private files outside the repo. It writes one committed file, `data/witness.json`, which the nightly build reads offline.

**Tech:** Node 24 type stripping, Vitest 5, the existing polite client (`http.ts`). No new dependency.

## Global constraints

- Free tools only. No new dependency. Scripts run as `node file.ts`: no enum, `import type`, relative imports ending in `.ts`.
- Tests never touch the network: `src/pipeline/no-network.ts` is the Vitest setup file, and tests that spawn a CLI use `node --import src/pipeline/no-network.ts`. No test passes `--live` to the witness command except to check that it refuses.
- No workflow, script or `package.json` script other than `data:witness` refers to the witness command. A test guards this (B1).
- Squad votes are published (Wikipedia, CC BY-SA 4.0; `ref` names the article). Witness values are never published, cached in `data/`, logged in CI, or written to `report.md`.
- `bash check-fast.sh` before every commit. Small conventional commits ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Never touch `src/app/` (another branch works there).
- Never run the checks while `data/pool.json`, `data/ids.json` or `data/report.md` have uncommitted changes (the incident of 4 October).
- Network in tasks: none, except A8 and B10, which Jalel starts.
- Do not bump `CACHE_VERSION`: new cache sources get their own `SHAPES` entries, and old copies stay valid (review L1).
